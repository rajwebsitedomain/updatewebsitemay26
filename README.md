## ✨ Features

- **Neobrutalist design** — bold borders, flat shadows, high-contrast palette
- **Fully responsive** — mobile-first layout with custom mobile navigation
- **SEO optimized** — structured data (JSON-LD), Open Graph, Twitter Cards, geo meta tags
- **Contact form** — powered by Web3Forms with real-time status feedback
- **Animated marquee** — scrolling tech stack ticker
- **Scroll reveal** — elements animate in on viewport entry
- **CV download** — one-click resume download from nav and hero

## 🔍 SEO Implementation

This site is fully SEO-optimized with:

- ✅ Keyword-rich `<title>` and `<meta description>` (150–160 chars)
- ✅ Open Graph tags for LinkedIn/Facebook sharing
- ✅ Twitter Card tags for X/Twitter sharing
- ✅ Local SEO geo meta tags (`geo.region`, `geo.placename`, `geo.position`)
- ✅ Canonical URL
- ✅ `robots` meta with `max-image-preview:large`
- ✅ **JSON-LD Structured Data:**
  - `Person` schema (name, job, education, skills, contact)
  - `WebSite` schema
  - `BreadcrumbList` schema
  - `ItemList` schema for all projects

## 🖥️ Local Development

No build tools required — this is a plain HTML/CSS/JS project.

```bash
# Clone the repo
git clone https://github.com/singhrajvardhan/portfolio.git
cd portfolio

# Open directly in browser
open index.html

# Or serve with any static server
npx serve .
# or
python3 -m http.server 3000
```
